# Practice files

This repository contains all the practice files that are used during the tsa frontend learning.

- check that you have node installed with 

```
node -v 
```

If node not installed - download from [here](https://nodejs.org/en)

using vite - install react scaffold 

```
npm create vite@latest . -- --template react 
```


For those struggling to run this code npm create vite... Window users

Close your vs code
Search powershell
Click run as administrator 
Paste this code:
Set-ExecutionPolicy RemoteSigned -scope CurrentUser
When asked a question 
Type Y
Press enter

Close it
Open vs code as run the npm command again 
When asked a question 
Type Y
Press enter 

When asked another question use your arrow key and enter ignore current files and you're done
